# 04 · 工作台页面与交互说明

> 纯原生 HTML/CSS/JS 单页应用（无前端框架），由服务端 `public/` 目录直接托管。
> 登录后左侧固定导航，右侧主区域按 `#/路由` 渲染；所有请求走 `Authorization: Bearer <token>`（token 存 localStorage，401 自动回登录页）。

## 2. 各页面交互说明

### 登录
- 默认回填 `admin`；输入密码回车或点击「登 录」；错误信息就地显示。
- 页面提示默认账号 admin/admin123（演示环境）。

### 仪表盘
- 8 张统计卡：账号（总/在线/异常）、在架商品（总/虚拟）、今日消息/自动回复、今日订单/金额、待发货、卡密库存、任务（启用/失败）、今日风控事件。
- 近 7 天趋势表（消息/订单/金额）、任务概览（状态/上次/下次执行时间）、最近回复日志与系统日志。
- 「刷新」按钮重新拉取。

### 消息会话
- 左侧会话列表（15 条/页，含未读红点、账号与商品摘要、最后消息），5 秒轮询刷新可见状态。
- 点击会话 → 右侧加载最近 100 条消息（买家左/客服右气泡，自动回复标注 🤖 与来源），同时调用已读接口清零未读。
- 之后每 3 秒按 `after_id` 增量拉取新消息自动追加并滚动到底。
- 底部输入框 + 「发送」按钮：客服手动回复（发送后立即增量刷新）。

### 自动回复规则
- 规则表：类型/匹配方式/关键词/回复内容/优先级/作用域（全局·账号·商品三列展示）/启停/命中次数。
- 「新增/编辑」弹窗：规则类型（文本关键词、图片关键词、默认回复）、匹配方式（包含/精确/正则）、关键词（逗号分隔）、回复文案（含变量说明）、优先级、作用账号/商品下拉、每会话一次、启用。
- 「停用/启用」即时切换；删除需二次确认。
- 页面顶部提示匹配优先级：商品专属 > 账号专属 > 全局；未命中走默认回复（商品 > 账号 > 全局）。

### 商品管理
- 商品表：价格/库存/虚拟标记/状态/擦亮次数与最近擦亮/卡密可用与已售计数。
- 操作：擦亮（触发风控间隔校验，被拦截会 toast 风控提示）、上架/下架、编辑、删除（有进行中订单被拒绝）。
- 「批量发布」弹窗：选账号 + 模板 + 数量（1-20，标题 `{n}` 替换序号）。
- 「发布模板」弹窗：模板列表（可删除）+ 底部内嵌新增表单。

### 卡券库存
- 上半区卡券产品表（可用/已售/总数）、「新建卡券产品」（仅虚拟商品可选）、「导入卡密」多行文本（每行一条）。
- 下半区卡密明细（产品/状态过滤 + 分页）。

### 订单管理
- 状态与发货状态双过滤。
- 操作：详情弹窗（发货内容原文 + 发货日志时间线）、发货（待发货/失败的虚拟订单手动补发）、评价（已发货未评价订单）。

### 账号管理
- 状态过滤；表格含三自动化开关展示、Cookie 过期时间、商品/会话计数。
- 操作：上线/下线、刷新 Cookie（模拟顺延 7 天）、编辑（弹窗可改 Cookie 与三开关）、删除（二次确认）。

### 定时任务
- 任务表：类型中文、作用账号、间隔、上次状态徽标、上次结果、上次/下次执行、成功/失败次数。
- 「立即执行」同步等待结果并 toast 执行消息；「编辑」可改名称/间隔/启停（间隔变化自动重排下次执行时间）；「历史」弹窗展示最近 15 次执行（状态/结果/处理数/耗时）。

### 通知中心
- 渠道表（类型、mock:// 地址说明）+ 新增/编辑/删除。
- 通知规则表（事件→渠道）+ 新增（事件类型下拉）。
- 推送日志最近 10 条（mock 状态标注）。

### 日志中心
- 三标签页：回复日志 / 系统日志 / 风控日志，各自独立分页与刷新。
- 回复日志列：买家消息、结果徽标（成功/失败/已过滤/跳过）、决策原因（sent/default_sent/filtered/risk_rate_limited/account_offline/auto_reply_disabled/system_message/no_reply/send_failed）、回复策略（keyword_item/keyword_account/keyword_global/default_*）、命中关键词、回复内容。

### 系统设置
- 全部设置项表单化展示（int→数字框、enum→下拉、string→文本框），含默认值与说明。
- 「保存全部」批量提交；非法值由后端 40001 校验并 toast。

### 模拟控制台
- 三张操作卡：
  1. **模拟买家发消息**：账号/买家昵称/关联商品/内容 → 显示受理结果 JSON（命中规则、策略、延迟毫秒）；回复在随机延迟后异步发出。
  2. **模拟买家下单**：账号/商品/数量/买家昵称 → 显示订单与自动发货结果（卡密内容）。
  3. **Cookie 过期检查**：账号 → 显示检查状态（ok/expiring/expired）。
- 执行结果区以 JSON 展示，并提示去「消息会话」「日志中心」观察链路效果。

## 3. 端到端演示路径（新装环境 5 分钟）

1. 登录 → 仪表盘确认种子数据。
2. 「模拟控制台」发买家消息「在吗」→ 数秒后到「消息会话」看到自动回复（默认回复或「在的亲~」）。
3. 「模拟控制台」对虚拟商品下单 → 返回自动发货结果（卡密内容）；「订单管理」看到 delivered，「卡券库存」可用数 -1。
4. 「通知中心 → 推送日志」出现新订单 mock 推送记录。
5. 「定时任务」对「商品定时擦亮」点「立即执行」→ toast 执行结果；「日志中心」三类日志可查。
6. 「账号管理」对账号B 点「刷新 Cookie」消除 Cookie 预警；「日志中心→风控日志」查看限流/擦亮拦截/Cookie 预警记录。

## 4. 基础能力说明（配置/任务状态/日志/异常）

- **配置**：`.env`（服务端口/数据库/日志级别/会话时长）+ 系统设置页（引擎与风控参数，运行时生效，无需重启）。
- **任务状态**：never/running/success/failed 徽标实时可查；失败自动通知；僵尸任务 10 分钟自愈；手动执行不受启用状态限制。
- **日志**：四路留存——控制台、`logs/app-YYYY-MM-DD.log` 文件、`xy_system_logs`（数据库）、业务日志表（回复/发货/任务/通知/风控各自独立）。
- **异常处理**：接口层 ApiError 统一包装；全局 uncaughtException/unhandledRejection 兜底记录；异步回复失败落库；发货事务回滚 + 补发机制；优雅停机。详见 docs/03 §6。
