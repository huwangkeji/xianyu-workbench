# 闲鱼自动化工作台（xianyu-workbench）
技术栈限定：**Node.js（≥22.5，实测 v24）+ SQLite（Node 内置 `node:sqlite`，单文件数据库）**。
**npm 依赖为零**：无需安装 MySQL 或任何第三方包；HTTP 服务、路由、鉴权、调度、前端均为原生实现，无任何框架。

## 功能总览（20 个页面 / 9 大业务系统）

**经营驾驶舱**：店铺总览 + 六大模块实时指标 + 每日待办与经营建议（每日运营助手定时生成简报，可 AI 解读）

**自动化核心**：多账号与 Cookie 管理 · 关键词/图片/默认回复引擎（随机延迟+频率风控）· 卡密自动发货与补发 · 在线会话与手动接管 · 定时任务（擦亮/订单同步/补发/评价/Cookie 检查/客户跟进/行情扫描/每日简报）· 通知中心（企业微信/钉钉/飞书/Bark/webhook，mock 支持）· 风控日志

**经营分析**：
| 系统 | 核心能力 | 核心价值 |
| --- | --- | --- |
| 📈 流量中心 | 曝光/浏览/收藏/咨询/成交按天统计；高曝光低点击、高浏览低成交、流量下滑自动诊断；按漏斗生成优化建议 | 知道商品为什么卖不出去 |
| 🔍 市场雷达 | 买家搜索关键词热度、行业热门商品、竞品价格追踪（涨/降价）、**竞品预警**（降价/新进入/销量激增+通知推送）、**机会雷达**（需求空缺/新需求/调价空间/高意向催单）、同款价格区间对比 | 知道应该卖什么 |
| 🧰 商品优化 | 商品体检打分、发布素材库、发布前风险检查、**标题实验室**（关键词覆盖+结构建议+变体生成+AI 生成）、**图片实验室**（首图检查）、**商品智能估价**（市场行情×成色系数+保本托底+AI 点评） | 提高商品竞争力 |
| 👥 客户中心 | 咨询自动分类、意向评分、聊天记录归档、未成交客户跟进提醒、常见问题统计 | 减少客户流失 |
| 💰 利润中心 | 收入/货物成本/运费包装/平台服务费/退款损失/净利润/利润率（汇总+按商品明细）、**利润计算器**（净利/保本价/目标利润率建议售价） | 知道到底有没有赚钱 |
| 🛡️ 风险中心 | 账号状态/Cookie 失效/商品违禁词/重复铺货/售后超时/任务异常/风控事件 七类一键扫描 | 降低经营风险 |

| 📋 商品经营诊断 | 单商品综合诊断（质量+流量+价格+咨询+利润五域聚合→评分→行动清单）+ 全店诊断总览 + **AI 经营处方** | 核心差异化 |

**🧠 AI 全智能（v3）**：「AI 控制台」配置大模型供应商，内置 9 家国内外厂家预设（DeepSeek/通义千问/Kimi/智谱GLM/豆包/MiniMax/OpenAI/Claude/Gemini），三种协议适配（OpenAI 兼容/Anthropic/Gemini）。AI 赋能：**自动回复兜底**（无规则命中时大模型生成，失败自动降级默认回复）、**驾驶舱 AI 解读**、**诊断 AI 处方**、**标题 AI 生成**、**估价 AI 点评**、AI 助手对话测试。连通性测试 + 失败原因落库，未配置时所有功能自动降级为基础引擎。

## ⚠️ 合规与边界说明（先读）

- 与闲鱼平台的**真实对接（WebSocket 私有协议、消息签名、Cookie 鉴权）本项目不实现、不逆向**。`connector_mode=live` 为预留扩展点，所有连接器动作返回 `50101`。
- 默认 `connector_mode=simulated`：通过内置**模拟连接器**（工作台「模拟控制台」注入买家消息/订单/流量/行情事件）驱动自动回复、自动发货、风控、通知与经营分析的**完整真实链路**（数据全部落库，可核查）。
- 上游项目 README 明确「仅供学习研究、禁止商业用途」；本项目同样仅用于学习研究，使用自动化工具存在账号风险，请遵守平台规则与当地法律法规。
- Cookie 字段在模拟环境为占位串，不会被发送到任何外部服务；AI 供应商的 API Key 仅保存在本机数据库，调用目标为所选厂家官方 API。

## 快速开始

```bash
cd xianyu-workbench

# 1) 配置（可选，默认 SQLite 库文件 data/xianyu_workbench.db，自动创建）
cp .env.example .env   # Windows: copy .env.example .env

# 2) 初始化数据库（建库文件 + 表结构 + 种子数据；--recreate 可重置）
npm run init-db

# 3) 启动（无需 npm install，零依赖）
npm start
#    工作台:  http://127.0.0.1:8080
#    健康检查: http://127.0.0.1:8080/health

# 4) 冒烟测试（另开终端，服务需在运行）
npm run smoke        # 79 项断言，覆盖全部自动化链路

# 其它
npm run check        # node --check 全量语法检查（34 个文件）
```

默认登录：`admin / admin123`（种子数据内置，仅演示环境；修改请改 `xy_users.password_hash`，格式 `scrypt$salt$hash`，可用 `src/auth.js` 的 `hashPassword` 生成）。

**扫码添加账号**：账号管理页 →「📱 扫码添加」→ 用闲鱼 App 扫一扫确认，即可把真实 Cookie 捕获入库（支持多账号，按 `unb` 去重，重复扫码自动更新凭证）。该功能调用闲鱼 passport 真实登录端点（`services/qrlogin.js`，参照 xianyu-super-butler 移植），业务自动化链路仍为模拟实现；仅用于学习研究，注意账号风控风险。

**账号可用性检查**：账号管理页 →「🔍 可用性检查」：真实扫码账号调用闲鱼 token 接口校验凭证是否在线/掉线（并自动合并刷新的 Cookie）；演示/手填账号按状态与过期时间模拟判定。

**生产模式 / 演示模式**：系统默认**生产模式**（无任何演示数据，仅管理员/系统设置/定时任务）；「演示模式」页可一键切换到演示模式（独立数据库 + 各功能丰富演示数据 + 模拟控制台注入买家消息/订单），切换时服务自动重启并要求重新登录，两个模式数据完全隔离、随时互相切换。

## 已验证能力（冒烟测试 125 项 / 连续两轮全绿 + 浏览器逐页实测）

- 鉴权：登录/登出/令牌失效/未登录拦截
- **自动回复**：关键词命中（商品>账号>全局优先级）、变量替换（`{买家昵称}` 等）、随机延迟后异步发出、默认回复兜底、过滤词拦截、单账号每分钟限流（超频记风控日志）
- **自动发货**：模拟下单→卡密事务扣减→自动发送→订单/发货日志→库存扣减核对→失败补发（任务与手动）→自动/手动评价→标记退款
- **定时任务**：5s 调度扫描、手动执行、执行历史、Cookie 检查预警、客户跟进提醒、行情扫描
- 商品批量发布（模板 `{n}`）、发布日志、卡密批量导入
- **流量分析**：三类诊断（高曝光低点击/高浏览低成交/流量下滑）+ 漏斗优化建议 + 按天数据录入
- **市场监控**：关键词热度、行情扫描（热门/竞品/新需求、涨降价徽标）、同款价格区间对比
- **商品优化**：一键体检（标题/描述/首图/价格竞争力/违禁词/发货能力）、素材库、发布前检查拦截违禁词
- **客户管理**：自动分类与意向评分、聊天归档详情、待跟进提醒与标记、FAQ 统计
- **利润分析**：收入/成本/服务费/退款损失/净利润/利润率，汇总与商品明细口径一致
- **风险中心**：七类风险一键扫描（Cookie/售后超时高危、重复铺货、任务异常、风控事件）
- 日志中心：回复/系统/风控三路查询；通知：事件订阅 + mock 渠道推送记录
- 系统设置：类型校验、未知项拒绝、热生效

## 已知限制

- 会话为内存态，服务重启后需重新登录（24h 滑动续期）。
- 风控频率窗口为内存态，重启计数归零。
- AI 大模型回复（上游 F03）未实现；仅关键词/默认/图片关键词规则。
- 与闲鱼真实对接未实现（见合规说明），`connector_mode=live` 全部动作返回 50101。
- 订单 `completed/closed/refunding`、买家退款等尾部流程为预留状态，未模拟。
